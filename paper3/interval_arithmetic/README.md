# Interval certificates of the proper-time branch at equal radii

Computer-assisted parts of the propositions on the certified grid of critical separations and on the interior
Maxwell angle (supplementary material, section *The certified critical separations and the Maxwell example*).
Everything runs in outward-rounded interval arithmetic (`mpmath.iv`, 20 digits); derivatives in `t` are exact jets,
and integrals in `u` are enclosed with a midpoint rule plus a Lagrange remainder. The value of `q` is an interval that
contains both the decimal rational (for example 6/5) and its binary64 value.

| File | Role | Time |
|---|---|---|
| `jets_nested.py` | nested second-order jets (t outer, u inner), quadrature with remainder, enclosure of 2R0, directed decimal output | library |
| `jets_t.py` | first-order jets in t and the zeroth-order quadrature used as a fast first stage | library |
| `critical_separation_estimate.py` | 30-digit floating-point estimate of the root of ell - 2R0, only to place the certified box (not a certificate) | library |
| `unimodality.py` | Delta is unimodal on [t_lo, t_hi]: bisection with labels P (Delta' > 0), C (Delta'' < 0), N (Delta' < 0) and the criterion `[PC]*[CN]*` with at least one C | about two hours for the 20 cases (10 processes; the longest case about 72 minutes) |
| `edges.py` | the edges (2, t_lo] and [t_hi, r0): Delta' > 0 near 2 and < 0 near r0 | about a minute |
| `critical_separation.py` | enclosure of delta_c/pi for the 20 grid cases (Table *Certified enclosures* of the main text) | a few minutes |
| `maxwell_angle.py` | interior Maxwell angle at q = 1.001, r0 = 1500M: delta*/pi in [0.677106398319, 0.677112764518], with the minimal margin 3e-5 M of the covering | about 75 minutes |

Run the scripts from this folder. The grid is q in {1.2, 1.5, 2, 4, 10} and r0 in {4, 6, 10, 20} (M = 1); the main
text uses q = 6/5, and the cases with q >= 3/2 are an independent check of the analytic theorem there.

## Archives

- `leaves_unimodality/q{q}_r0{r0}.json`: every leaf of the unimodality bisection, with exact end points in
  hexadecimal, label, quadrature stage, K and the bound proved with directed rounding.
- `leaves_maxwell/maxwell_q1.001_r01500.json`: the leaves of steps A and C, the enclosures of step B and the
  analytic margins of the Maxwell certificate.

All archives were regenerated by the published scripts, in the runs whose logs are in `../results/`. The twenty
unimodality archives are identical byte for byte to those of the original (Italian-language) version of the same
program; the Maxwell archive equals the original one in every field except `generator_sha256`.

## Expected outputs

`../results/interval_edges.txt`, `../results/interval_critical_separation.txt`, `../results/interval_unimodality.txt`
and `../results/interval_maxwell_angle.txt`. A case is accepted only if the line says `CERTIFIED` (or `OK` for both
edges).
