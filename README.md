# NonStationaryBrachistochrone2

Reproducibility packages for the second group of papers on **controlled-rail brachistochrones**: the fastest
timelike worldline from a fixed departure event to a fixed spatial target, with free arrival time, when a controlled
thrust holds the traveller at a maintained energy. The first group (Paper I, FLRW and Vaidya; Paper II, conformal
Kerr) is in the repository [NonStationaryBrachistochrone](https://github.com/ImanetorX98/NonStationaryBrachistochrone).

| Folder | Paper | Status |
|---|---|---|
| [`paper3/`](paper3/) | *Global minimality of controlled-rail brachistochrones in conformal Kerr and Vaidya spacetimes* (Paper III) | computer-assisted steps, symbolic checks, diagnostics and LaTeX sources; start from [`paper3/README.md`](paper3/README.md) and [`paper3/RESULTS_MAP.md`](paper3/RESULTS_MAP.md) |
| [`paper4/`](paper4/) | controlled-rail brachistochrones in the McVittie metric (Paper IV) | in preparation |

Each folder is self-contained: its scripts are run from inside it and its logs are in its own `results/`.

[`CITATION.cff`](CITATION.cff).
